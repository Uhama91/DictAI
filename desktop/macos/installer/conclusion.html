Ouvrez DictAI dans Applications

L’assistant de configuration vous guide pour le microphone, la reconnaissance vocale, l’accessibilité et le compte Google facultatif.

Utilisez le même compte que dans DictAI sur votre téléphone et votre tablette pour retrouver vos données partagées.

Rejouer la configuration

Dans DictAI, choisissez Réglages → Reprendre la configuration. Vous pouvez changer de compte dans l’assistant. Vos données restent conservées dans leurs espaces respectifs.

Pour reproduire exactement une première installation, avec un Trousseau et des autorisations vierges, utilisez une nouvelle session utilisateur macOS.
