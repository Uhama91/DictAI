## Mac changes since 0.4.9

- **Return to writing after editing.** External focus is restored after transcript edits, and the insertion target is resolved at insertion time.
- **Continue the same thought.** Manual edits, sentence continuity, and casing stay protected as recognition continues across pauses. A pause alone does not create a new sentence.
- **Resume with Option.** One Option press while paused resumes the current draft. One press while listening finishes and inserts; two quick presses pause or resume. Three cancel without inserting and preserve a recoverable draft.
- **Keep the editor clear.** Remembering a correction immediately removes its row and button, restores the editor's height, and leaves no persistent success message. Existing learned rules are not offered again.
- **Paste once in supported custom editors.** Version 0.4.14 uses a single native Paste command for cmux/OpenCode and other custom editors that expose a supported native Paste action. This avoids duplicate insertion. DictAI never presses Enter or Send.
- **Review a recovered draft.** A restored account draft opens ready to review and insert, without submitting it to another app.

The floating editor and full, resizable window offer the same dictation controls. Unsupported text fields keep the transcript available to copy; secure and password fields are excluded. The local rolling history keeps the last ten dictations, while saved notes remain separate until you delete them.

## Validation

The Mac suite passes **202 tests on Apple silicon and under Rosetta**. The maintainer has validated the real Mac voice workflow and insertion into cmux/OpenCode without duplicate text. Speech recognition on a physical Intel Mac remains unverified.

Android is unchanged in this release. These Mac results do not establish additional Android device compatibility.

## Install on Mac

1. Quit DictAI, then run `DictAI-macOS.pkg`.
2. Open `/Applications/DictAI.app`.
3. Check microphone access, speech recognition, and Accessibility in macOS settings. After an ad hoc signed update, you may need to remove and re-add the exact installed `/Applications/DictAI.app` entry in Accessibility, then refresh the shortcut check in DictAI.
4. Try a short dictation in TextEdit before using your usual target app.

This is a test package, ad hoc signed and **not Apple-notarized**. If macOS blocks it, follow [Apple's guidance for opening apps](https://support.apple.com/en-us/102445). Install over the existing app to preserve local data.

Mac recognition uses Apple Speech with on-device recognition required and no remote speech fallback. See the [Mac setup and usage guide](https://github.com/Uhama91/DictAI/blob/dictai-20261014-macos-0.4.14-preview/desktop/macos/README.md) for controls and recovery.

## Update Android

Install `DictAI-android.apk` over the existing app. The APK and its existing test signature are unchanged from Android 0.9.18; updating in place with the matching signature preserves app data.

For a first installation, follow the setup assistant for microphone access, the local speech model, and display over other apps. Accessibility enables insertion into supported fields and captures you request. Xiaomi, Redmi, and Poco devices may need additional restricted-settings, battery, and automatic-startup settings.

## Optional services

No account is required for local-only use. Optional Google sign-in syncs saved notes, folders, images, vocabulary, and shared preferences through Supabase. Sync is periodic. Secrets, permissions, installed models, audio, drafts, local recent history, and panel positions do not sync. Notes created on Mac without an account stay in the local scope and are not automatically imported on sign-in.

Optional OpenRouter correction sends the transcript and useful vocabulary, never recorded audio for this correction. Provider charges may apply. The API key stays on the device and uses Keychain on Mac.

The app interface remains in French.
