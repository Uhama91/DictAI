Privacy Policy

Last updated: September 13, 2026

DictAI is an Android dictation app that records speech, transcribes it locally, and inserts the result into text fields across apps. Your privacy is a core feature of the app, not an afterthought.

Data handling

DictAI's normal transcription path runs on the device using models that you download into the app's private storage.

Local transcription

Audio is processed on-device using local speech recognition models. Audio does not leave your device.

Optional cloud cleanup

If cloud cleanup is enabled, the transcript text, selected formatting instructions, and any configured vocabulary or protected spellings are sent directly from the device to OpenRouter. This step is optional and does not send the recorded audio.

API key

If you enable cloud cleanup, your OpenRouter API key is stored in secure local app storage. It is used only to authenticate the request sent directly from your device to OpenRouter.

I do not operate a relay server. Your keys and your data never touch any infrastructure controlled by me.

Accessibility Service

DictAI uses Android Accessibility Service to identify the currently focused text field and insert dictated text after you explicitly interact with the floating overlay button. It can also capture a screenshot only when you explicitly request the note-capture feature.

  • It does not monitor your browsing.
  • It does not collect screen content for analytics.
  • It does not perform background automation or "keylogging."

Data collection

I do not run a backend for DictAI. I do not collect user accounts, analytics, crash reports, or uploaded recordings. Dictation drafts and notes remain in local app storage. Captures stay local unless you explicitly save them to Photos or export or share them.

OpenRouter and the model provider selected through it may process the transcript text, selected formatting instructions, and configured vocabulary or protected spellings according to their own terms and privacy policies.

Open source

Because trust is earned, DictAI is open source. You can audit the code yourself on GitHub to verify how your data and permissions are handled.

Contact

For privacy questions, open an issue in the DictAI repository.
