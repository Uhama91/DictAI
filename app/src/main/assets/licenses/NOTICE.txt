DictAI
======

DictAI is a modified derivative of Phone Whisper by kafkasl.

Upstream provenance
-------------------
The imported upstream snapshot is commit 8356089931a6f771facc18796c8912460589ec2b
from https://github.com/kafkasl/phone-whisper. The corresponding upstream
Apache-2.0 license was added upstream in commit
e6518cda437ed2c266f36cf476db857fa2690d87. The upstream snapshot used for this
fork did not contain a NOTICE file.

Files derived from Phone Whisper and modified for DictAI carry a short
modification notice. New files and third-party components may have separate
terms; see app/src/main/assets/THIRD_PARTY_NOTICES.txt and
app/src/main/assets/licenses/.

Bundled component references
----------------------------
The bundled sherpa-onnx native libraries identify version 1.13.4. Its license
source is https://github.com/k2-fsa/sherpa-onnx/tree/v1.13.4 and its license
text is included at
app/src/main/assets/licenses/sherpa-onnx-1.13.4-LICENSE.txt.

The bundled ONNX Runtime native library identifies version 1.27.0. Its license
source is https://github.com/microsoft/onnxruntime/tree/v1.27.0 and its license
text is included at
app/src/main/assets/licenses/onnxruntime-1.27.0-LICENSE.txt.

The separate meeting runtime, libdictai_meeting.so, uses NVIDIA
NeMo-Speech.cpp at commit 97a15afa5caa9bce5baaa86c1184103877af4101 with
statically linked GGML and SentencePiece. Its source revisions, model
artifacts, and bundled notices are recorded in
app/src/main/assets/licenses/meeting/SOURCES.md. The complete upstream
NeMo-Speech.cpp third-party notice is retained there as
nemo-speech-THIRD_PARTY_NOTICES.md, including the attribution for portions
derived from parakeet.cpp. That upstream notice also describes optional
components outside this Android build; the SOURCES file identifies the
dependencies selected for the meeting runtime.
